# 🎮 Split Landing Page

Landing page interactiva de **PlayStation 5** y **Xbox Series X**, con una pantalla dividida que destaca cada consola al pasar el cursor.

## Screenshot

![Split Landing Page-A](./screencapture_1.png)
![Split Landing Page-B](./screencapture_2.png)

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Diseño dividido en dos paneles.
- Expansión del panel seleccionado al **75%** y reducción del otro al **25%**.
- Transiciones suaves y efectos hover.
- Diseño responsive.

## Ejecución

Abrir `index.html` en el navegador o utilizar **Live Server** desde VS Code.

No requiere instalar dependencias.
